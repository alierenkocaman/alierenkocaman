### Focus Areas

- **Edge AI & Computer Vision:** Real-time micro-UAV detection, multi-state perception pipelines, Kalman tracking, and optical-flow Camera Motion Compensation targeting NVIDIA Jetson hardware.
- **On-Prem / Air-Gapped LLM Systems:** Offline, PDF-agnostic technical document Retrieval-Augmented Generation (RAG) architectures built for isolated environments.
- **Cross-Platform Mobile & App Security:** Kotlin, Jetpack Compose, Kotlin Multiplatform (KMP), MVI architecture, and C++ NDK reverse-engineering hardening.
- **Cybersecurity & Infrastructure:** Linux server hardening (Nginx, SSL, Fail2Ban), network/web security assessments, and CTF engineering.
- **Embedded & Hardware Telemetry:** ESP32 wireless telemetry, LiFePO4 battery pack engineering with Smart BMS, and RF signal acquisition prototypes.
